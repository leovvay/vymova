# Vymova

Разбор ошибок произношения, грамматики и лексики студентов по записи урока украинского.
Загружаете запись урока, отмечаете, кто есть кто, через 15–20 минут получаете один PDF
на весь урок: что каждый студент произносит не так (подтверждено двумя независимыми проверками),
грамматика, слова из других языков, что тренировать — и полную фонетическую расшифровку
со ссылками на аудио каждой реплики.

Всё работает на вашем компьютере. Записи никуда не выкладываются, кроме сервисов распознавания
(ElevenLabs и Google Gemini) по вашим ключам.

## Установка (Windows)

1. Установите **Docker Desktop**: https://www.docker.com/products/docker-desktop/ — при установке
   оставьте галочку «Use WSL 2», после установки перезагрузите компьютер. Нужно 8 ГБ оперативной
   памяти и ~10 ГБ места на диске.
2. Откройте страницу [Releases](https://github.com/leovvay/vymova/releases/latest), скачайте
   `vymova-zapusk.bat` и положите, например, на рабочий стол.
3. Запустите его двойным кликом. В первый раз программа скачивается (несколько гигабайт) — это
   долго, дальше запуск занимает секунды. Когда всё готово, откроется браузер.
4. Откройте «Настройки» и вставьте ключи:
   - **ElevenLabs** — https://elevenlabs.io → Profile → API Keys (нужен доступ к Speech to Text);
   - **Gemini** — https://aistudio.google.com/apikey. Нужен **платный** тариф: на бесплатном
     Google может использовать присланные данные, а это голоса ваших студентов.

Уроки и PDF лежат в папке `Документы\Vymova\lessons`. Чтобы обновить программу — просто снова
запустите `vymova-zapusk.bat`.

## Как это работает

1. Расшифровка дословно, с ошибками и разделением голосов — ElevenLabs Scribe.
2. Вы отмечаете голоса; реплики каждого студента режутся на клипы.
3. Gemini прослушивает весь урок и отмечает подозрительные места (кандидаты).
4. Две разные модели Gemini **вслепую** записывают фонетику каждой реплики. Ошибка считается
   подтверждённой, только если её услышали обе, а цитаты из их записей механически проверяются.
5. Акустика без языковых моделей: wav2vec2 переводит звук в фонемы, они сравниваются со
   словарным произношением (Викисловарь) с поправкой на то, как модель искажает речь носителей.
6. Грамматика, лексика, сводка по группе — и PDF.

## Разработка

```
cd backend && uv venv && uv pip install -e ".[ml]"
DATA_DIR=/tmp/vymova-data MODELS_DIR=/tmp/vymova-models .venv/bin/vymova serve
cd frontend && npm install && npm run dev
```
Сборка образа: `docker build -f docker/Dockerfile -t vymova .`

## Атрибуция

Калибровка акустики построена на датасете **FLEURS** (Google, CC-BY-4.0), украинская часть.
Эталонное произношение слов — **Викисловарь** (en.wiktionary.org, CC-BY-SA).
Модели: facebook/wav2vec2-lv-60-espeak-cv-ft, facebook/wav2vec2-xlsr-53-espeak-cv-ft (Apache-2.0),
microsoft/wavlm-base-plus-sv.
